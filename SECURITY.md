# Security

Please do not open a public issue for a security problem.

Report it privately: **Security** tab → **Report a vulnerability**. Include what is affected, the steps to see it, and the impact.

A first reply comes within 7 days. Please keep the problem private until it is fixed.

Covered: the website and its source on `main`.

Not a security problem: the publishable Supabase key in `website/grid-config.js` (public by design).

Do not access other people's data, run load or denial-of-service tests, or scan the site or its database.
