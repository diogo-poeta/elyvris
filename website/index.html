01 / START

Prepare a component

Import gdsfactory, activate its example process kit and create an empty component. Run this first; the following snippets build on it.

import gdsfactory as gf

gf.gpdk.PDK.activate()
layout = gf.Component()

A component is a container for shapes, other components and connection points. The generic PDK is for learning; check a foundry’s rules before fabrication.

02 / SHAPES

Add geometry

Create a straight waveguide and place it in the layout. Its ends have connection points called ports.

waveguide = gf.components.straight(length=10, width=0.5)
straight = layout.add_ref(waveguide)
print(straight.ports)

For a custom shape, give the polygon’s corner coordinates and a GDS layer number.

layout.add_polygon([(0, 2), (4, 2), (4, 4), (0, 4)],
                   layer=(1, 0))
03 / ARRANGE

Move an instance

An instance is a placed copy of a component. Move the waveguide 5 µm upward; the original component remains reusable.

straight.movey(5)

Moving a connected instance afterwards can break its alignment. Check connections and layer rules before using a layout.

EXAMPLES / GEOMETRY

Circles, rings and arrays

Use the designer above to combine simple shapes and download a Python script. For ports, bends, routing and additional component types, see the gdsfactory references below. The ring example is a geometry, not a resonator simulation.

disk = gf.components.circle(radius=3, layer=(1, 0))
layout.add_ref(disk)
04 / SAVE & VIEW

Open the result

Save the layout, then use File → Open in KLayout to inspect the GDS file.

layout.write_gds("my_layout.gds")

The filename is relative to the folder from which you run Python. Writing to an existing filename may replace that file. A GDS layout describes geometry; it does not calculate optical propagation.

Model limits

Planar, isotropic, non-magnetic layers with a lossless incident medium. The substrate may be absorbing. Absorption in the finite layers is calculated as A = 1 − R − T. The checks cover selected cases and do not constitute experimental validation.
