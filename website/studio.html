Photonics Studio

Build a structure in 3D and edit its gdsfactory or Meep code.

Quick start

The example in four steps

  1. Select a pillar. Click one in the 3D view or in the shape list (the first one is already selected).
  2. Change its radius in the shape's form (the Radius field), for example to 120 nm.
  3. Look at the code. The Studio changed only the number in r = …, so all three pillars changed. Click in the code box when you have seen it.
  4. Save the project with “Save project” at the top. “Open project” reads the file back, in this or another browser.

    How it works
    • Build. Add shapes with the buttons or a sentence, then change the numbers. Click a shape in the 3D view to select it.
    • Code. The code follows your shapes. You can also edit or paste code and the 3D view follows. Select a shape and the lines of code that made it light up; put the text cursor on a line and its shape is selected. The page does not run Python: it reads a limited part of the language and tells you which lines it could not use, and why. In Meep code you typed or pasted, changing a size or a position in the form changes that one number in your text (or the variable it comes from); numbers that come from a formula are greyed and are changed in the code. Adding, deleting, dragging or changing the material of a shape still makes the Studio rewrite the code: if that happens, “Bring back my code” restores your text.
    • gdsfactory. The script draws the top view, one layer per material, and saves a GDS file that opens in KLayout. A layout has no height, so heights are kept as comments.
    • Layout file. “Download layout (.gds)” saves the layout itself, ready for KLayout, without running Python. It holds the same outlines and layers as the script; corners sit on a 1 nm grid, and round outlines are polygons with 144 corners. Shapes with an endless size are left out.
    • Measure. Press “Measure”, then click two points. The ruler catches points that lie exactly on a shape (its centre, face centres, corners, the outermost points of round shapes); elsewhere it takes the point on the plane z = 0. The distance follows when you change the shape. It is a distance in the drawing, not a simulated quantity. Esc clears it.
    • Meep. You get the geometry list, in the length unit set by “1 Meep unit = … µm” (1 µm unless you change it). The material lines are constant indices from the Elyvris library at the wavelength you choose; materials from your own code, and Meep’s own library models, are kept as you wrote them. Under your own code, the “Preview” box says what is drawn, approximated or left out. If your code makes an mp.Simulation, its cell (2D when the z size is 0) and its PML or absorber layers are drawn as thin outlines, and listed in the box with links to their lines; “Setup” under the view hides or shows them. Endless shapes stop at the cell walls, where Meep cuts them. Sources and flux monitors are drawn too, in front of the shapes. Every source has a double-headed arrow along its current or field (its polarisation). A travel arrow appears only where Meep launches light one way: a mode source (EigenModeSource) and a Gaussian beam. A plain mp.Source is a current that radiates to both sides, so it has none. Each flux plane has a “+ flux” arrow: the direction in which crossing power counts as positive (turned around by a negative weight). It is a sign convention, not the path of the light. These directions were measured in real Meep 1.30 runs. Nothing is simulated here.
    • Projects. “Save project” downloads a .elyvris.json file with the shapes, your code and the settings; “Open project” reads it back in any browser.
    • Start options. .
    • Figure. “Save figure” downloads the current view as a PNG with a legend of the materials. The background can be white paper, the dark stage with its grid (as on screen) or transparent. “Names and sizes” adds a label to each shape: its name (set under “Name in figures”, or its type) and the sizes that describe it, such as radius and height for a cylinder or the three edge lengths for a box. Identical copies share one label with “× N”. It is sized for print at 300 dpi: 1000 px is one journal column (8.5 cm), 2000 px is two (17 cm). The scale bar appears only in the Top, Front and Side views, which are drawn true to scale. The free 3D view uses perspective, where far things look smaller, so no single scale is valid there.
    • App and offline use. After one visit the Studio also opens without an internet connection. In Chrome or Edge, “Install app” adds it to your computer with its own icon and window; in Safari use Share → Add to Dock (or Add to Home Screen on a phone). It is the same page: no account, and your designs stay on this computer.
    • No simulation here. This page only draws. Run the code on your own computer.

    Commands the code box reads. Meep: mp.Sphere, mp.Cylinder, mp.Block, mp.Cone, mp.Ellipsoid, mp.Prism, mp.Medium(index=…), mp.inf, variables and arithmetic, for loops, if, lists and list comprehensions, simple functions (def), and a few math and numpy functions (sqrt, sin, cos, pi, linspace, arange). Not read: while, classes, mp.Wedge, files and other libraries. gdsfactory: circle, rectangle, ellipse, ring, straight, add_ref, move, movex, movey, add_polygon.
