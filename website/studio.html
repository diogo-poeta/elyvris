Build shapes, see them in 3D, get the code for gdsfactory and Meep.

The 3D view needs WebGL, which this browser does not provide. The shape list and code still work.

    Code

    How it works
    • Build. Add shapes with the buttons or a sentence, then change the numbers. Click a shape in the 3D view to select it.
    • Code. The code follows your shapes. You can also edit or paste code and the 3D view follows. The page does not run Python: it reads basic commands only and tells you which lines it could not use.
    • gdsfactory. The script draws the top view, one layer per material, and saves a GDS file that opens in KLayout. A layout has no height, so heights are kept as comments.
    • Meep. You get the geometry list, with 1 unit = 1 µm. The material lines are simple constant indices from the Elyvris library; replace them with your own models.
    • No simulation here. This page only draws. Run the code on your own computer.

    Commands the code box reads. Meep: mp.Sphere, mp.Cylinder, mp.Block, mp.Cone, mp.Ellipsoid, mp.Prism, mp.Medium(index=…), mp.inf, and simple variables such as r = 0.1. gdsfactory: circle, rectangle, ellipse, ring, straight, add_ref, move, movex, movey, add_polygon.
